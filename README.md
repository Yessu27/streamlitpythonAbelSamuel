# streamlitpythonAbelSamuel
Streamlit de um aplicativo para fazer previsões na sequencia de uma análise de MACHINE LEARNING

Concluí um projeto completo de Machine Learning voltado para análise de risco de crédito, seguindo rigorosamente a metodologia CRISP-DM do início ao fim. A jornada começou com uma análise exploratória aprofundada dos dados, entendendo distribuições, inconsistências e o comportamento da variável de inadimplência. Em seguida, avancei para a modelagem, comparando cinco abordagens diferentes: Dummy Classifier, Árvore de Decisão, Random Forest, XGBoost e LightGBM. A escolha do modelo vencedor foi baseada em métricas robustas — ROC AUC, PR AUC e acurácia — garantindo uma decisão orientada por dados e não por intuição. O XGBoost se destacou como o modelo mais equilibrado entre poder preditivo e generalização. Com o modelo definido, defini um limiar de decisão de 0.59, calibrado a partir de uma análise de custos entre falsos positivos e falsos negativos, refletindo o impacto real de conceder crédito a um mau pagador versus recusar um bom cliente. Utilizei SHAP para interpretar as decisões do modelo, tornando as previsões transparentes e explicáveis para o negócio. Por fim, o projeto foi levado à prática com o deploy de uma aplicação Streamlit, permitindo que analistas de crédito insiram os dados de um cliente e recebam, em tempo real, a probabilidade de inadimplência, a decisão de conceder ou recusar o crédito, e os principais fatores que influenciaram essa previsão.
